# Contributing to Namazu Elements

Thank you for your interest in contributing to Namazu Elements! This file points you at the right
place to get started.

## Getting started

- **What is this?** Namazu Elements is an open-source backend server for multiplayer games. See the
  [README](README.md) for an overview and the [project documentation](https://namazustudios.com/docs)
  for the full manual.
- **Building and hacking on the code** — build commands, repository layout, testing conventions, and
  the local development environment are covered in [HACKING.md](HACKING.md).

## Contributor License Agreement (CLA)

Contributions are made under the project's
[Contributor License Agreement](CLA.md), which you will be asked to sign as part of your first pull
request. The CLA enables the project's licensing structure: prior releases were made available under
the AGPL, current releases are made available under the
[Mozilla Public License 2.0](LICENSE.txt), and the project may be offered under additional licenses
in the future.

The canonical copy of the CLA is [CLA.md](CLA.md) in this repository, mirrored in the
[NamazuStudios/.github](https://github.com/NamazuStudios/.github) organization defaults and in the
HubSpot form linked from [HACKING.md](HACKING.md).

## Where to ask questions

- [GitHub Issues](https://github.com/NamazuStudios/elements/issues) — bug reports and feature requests.
- [GitHub Discussions](https://github.com/NamazuStudios/elements/discussions) — questions and ideas.
